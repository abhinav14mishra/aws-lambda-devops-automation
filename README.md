## Repository Structure

- `queue/` — Projects waiting to be published.
- `src/` — Projects already published.
- `.github/workflows/daily-project.yml` — Daily automation.
- `scripts/update_progress.py` — README progress updater.

## Automation

Every scheduled run:

1. Finds the lowest-numbered project in `queue/`.
2. Moves it into `src/`.
3. Marks that project as completed in this README.
4. Commits the change.
5. Pushes the commit to GitHub.
6. Removes `queue/` after the final project.

## Schedule

The workflow runs daily at **09:00 IST (03:30 UTC)** and can also be started manually from GitHub Actions.

## Security

Never commit AWS credentials, access keys, secrets, private keys, `.env` files, or generated deployment artifacts containing secrets.
